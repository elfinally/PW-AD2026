1. Comando: `git init`
   Descripción del comando: Inicializa un nuevo repositorio Git en una carpeta.
   Ejemplo de caso de uso: Crear un repositorio para comenzar un proyecto nuevo.

2. Comando: `git clone`
   Descripción del comando: Descarga una copia de un repositorio remoto.
   Ejemplo de caso de uso: Copiar un proyecto de GitHub a tu computadora.

3. Comando: `git status`
   Descripción del comando: Muestra el estado actual de los archivos del repositorio.
   Ejemplo de caso de uso: Revisar qué archivos fueron modificados o cuáles están pendientes de guardar.

4. Comando: `git add`
   Descripción del comando: Agrega archivos al área de preparación antes de hacer un commit.
   Ejemplo de caso de uso: Usar `git add archivo.txt` para preparar un archivo modificado.

5. Comando: `git commit`
   Descripción del comando: Guarda los cambios preparados en el historial del repositorio.
   Ejemplo de caso de uso: Usar `git commit -m "Agrega página principal"` para registrar cambios.

6. Comando: `git log`
   Descripción del comando: Muestra el historial de commits realizados.
   Ejemplo de caso de uso: Revisar qué cambios se hicieron anteriormente y quién los realizó.

7. Comando: `git branch`
   Descripción del comando: Permite consultar, crear o eliminar ramas.
   Ejemplo de caso de uso: Usar `git branch desarrollo` para crear una nueva rama.

8. Comando: `git switch`
   Descripción del comando: Permite cambiar de una rama a otra.
   Ejemplo de caso de uso: Usar `git switch desarrollo` para comenzar a trabajar en esa rama.

9. Comando: `git checkout`
   Descripción del comando: Permite cambiar de rama o recuperar versiones de archivos.
   Ejemplo de caso de uso: Usar `git checkout main` para cambiar a la rama principal.

10. Comando: `git merge`
    Descripción del comando: Une los cambios de una rama con otra.
    Ejemplo de caso de uso: Fusionar los cambios de la rama desarrollo con la rama main.

11. Comando: `git pull`
    Descripción del comando: Descarga los cambios de un repositorio remoto y los integra al repositorio local.
    Ejemplo de caso de uso: Actualizar un proyecto con los últimos cambios disponibles en GitHub.

12. Comando: `git push`
    Descripción del comando: Envía los commits locales a un repositorio remoto.
    Ejemplo de caso de uso: Subir los cambios realizados en tu computadora a GitHub.

13. Comando: `git remote`
    Descripción del comando: Administra las conexiones con repositorios remotos.
    Ejemplo de caso de uso: Usar `git remote -v` para comprobar a qué repositorio de GitHub está conectado el proyecto.

14. Comando: `git fetch`
    Descripción del comando: Descarga información y cambios del repositorio remoto sin integrarlos automáticamente.
    Ejemplo de caso de uso: Revisar cambios nuevos de GitHub antes de agregarlos al proyecto local.

15. Comando: `git diff`
    Descripción del comando: Muestra las diferencias entre archivos o versiones.
    Ejemplo de caso de uso: Revisar qué líneas de código fueron modificadas antes de hacer un commit.

16. Comando: `git rm`
    Descripción del comando: Elimina un archivo y registra su eliminación en Git.
    Ejemplo de caso de uso: Usar `git rm archivo.txt` para borrar un archivo del proyecto.

17. Comando: `git mv`
    Descripción del comando: Permite mover o cambiar el nombre de un archivo.
    Ejemplo de caso de uso: Usar `git mv viejo.txt nuevo.txt` para renombrar un archivo.

18. Comando: `git reset`
    Descripción del comando: Permite deshacer ciertos cambios o mover el repositorio a un estado anterior.
    Ejemplo de caso de uso: Usar `git reset archivo.txt` para quitar un archivo del área de preparación.

19. Comando: `git revert`
    Descripción del comando: Revierte los cambios de un commit anterior creando un nuevo commit.
    Ejemplo de caso de uso: Deshacer de forma segura un cambio que ya fue subido a GitHub.

20. Comando: `git stash`
    Descripción del comando: Guarda temporalmente cambios que todavía no se quieren registrar con un commit.
    Ejemplo de caso de uso: Guardar cambios incompletos para poder cambiar de rama y retomarlos después.
